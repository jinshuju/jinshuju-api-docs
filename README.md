# 金数据高级 API & SDK 文档

这是金数据高级 API 与 SDK 的官方文档仓库，面向企业高级版、商业合作版和第三方合作伙伴等高级集成场景。

如果你需要使用基础 API、Webhook、URL 传参、MCP 或表单嵌入，请访问 [金数据开放平台](https://open.jinshuju.net)。

## 适合谁使用

- 需要接入金数据高级 API 的企业客户
- 使用金数据 SDK 进行系统集成的商业合作伙伴
- 需要与金数据进行深度业务系统对接的开发者

## 快速开始

请先确认你的金数据账号和套餐是否已开通高级 API / SDK 权限。

- 高级 API 文档：[账户位于 jinshuju.net](jinshuju-net-api.md)
- SDK 文档：[账户位于 jinshuju.net](jinshuju-net-sdk.md)
- 企业组织授权流程：[Enterprise API OAuth Client Credentials Grant Flow](enterprise-api-org-client-credentials-grant-flow.md)

如果你不确定当前账号是否具备高级 API / SDK 权限，请联系金数据销售或客户经理。

## 与开放平台的关系

金数据开放平台提供基础 API、Webhook、URL 传参、MCP 和表单嵌入等通用开发者能力：

- 开放平台：[https://open.jinshuju.net](https://open.jinshuju.net)
- 基础 API 介绍：[https://jinshuju.net/help/articles/api-intro](https://jinshuju.net/help/articles/api-intro)

本仓库主要维护高级 API 与 SDK 文档，适用于更深度的企业集成和合作伙伴场景。
