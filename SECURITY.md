# Security Policy

If you believe you have found a security issue related to Jinshuju APIs, SDKs, or other Jinshuju projects, please do not open a public issue.

Please contact us at support@jinshuju.net with the subject line `[Security]`, and include enough detail for our team to investigate.

Do not include API keys, secrets, access tokens, private form data, customer data, SDK credentials, or other sensitive information in public issues or pull requests.
