# Contributing

Thanks for your interest in Jinshuju Advanced API and SDK documentation.

This repository contains documentation for Jinshuju advanced API and SDK integrations. We welcome fixes and suggestions that improve clarity, accuracy, examples, and developer experience.

## How to contribute

- For documentation fixes, open a pull request.
- For unclear content or missing examples, open an issue.
- For product support, account-specific questions, or API access questions, contact support@jinshuju.net or your Jinshuju account manager.

## Before submitting

Please make sure your contribution:

- Is focused on documentation or developer experience
- Does not include API keys, secrets, access tokens, private form data, customer data, SDK credentials, or internal integration details
- Uses clear and concise language
- Keeps links and examples accurate

## Project status

This repository is maintained by the Jinshuju team for advanced API and SDK documentation.
